HOP



IDEA PRINCIPAL

Se trata de un juego de plataformas estilo Arcade (similar al clásico Donkey Kong) donde el protagonista debe ascender por una estructura en zig-zag esquivando obstáculos físicos que caen rodando por la pendiente.



OBJETIVO DEL JUGADOR

El jugador debe controlar a un personaje y llevarlo desde la base del nivel hasta la bandera situada en la cima. Para ello deberá saltar entre plataformas inclinadas, evitar ser golpeado por las bolas que ruedan cuesta abajo y todo esto a contra reloj. El objetivo es sobrevivir con al menos 1 corazón de vida.



GÉNERO

Plataformas Arcade 2D de precisión.



PLATAFORMA

Se tratará de un juego offline creado para entornos "Windows".



RESUMEN

El juego se tratará de una aventura de una sola pantalla (o scroll vertical limitado) donde jugaremos con un personaje estilo "monigote". Tendremos un contador de puntuación y 3 vidas. El escenario estará compuesto por rampas inclinadas conectadas. Desde la parte superior, un generador lanzará obstáculos constantemente. El jugador gana al tocar la bandera final.



MECÁNICAS

Controles: El juego tendrá un sistema simple: Teclas de dirección (A/D o Flechas) para moverse lateralmente y Barra Espaciadora para saltar.



Físicas:



Gravedad: Afecta tanto al jugador como a los obstáculos.



Inercia: Los obstáculos (bolas) usarán físicas de RigidBody2D para rodar de forma realista por las pendientes.



Fricción: El jugador tendrá fricción suficiente para no resbalar en las cuestas, pero las bolas tendrán poca fricción para rodar rápido.



Sistema de Salud: El jugador cuenta con 3 corazones. Al recibir daño, perderá uno y tendrá una breve invulnerabilidad. Si llegan a 0, se reinicia el nivel.



Puntuación: Recoger monedas sumará puntos al marcador visible en la UI.



CARACTERÍSTICAS

Se tratará de un juego intuitivo sin necesidad de mucho texto.



Tendrá una ambientación minimalista (blanco, negro y colores pastel para resaltar elementos interactivos).



La dificultad radica en el timing del salto para cruzar los obstáculos rodantes.



TIEMPO DE DESARROLLO

El juego se desarrollará en Godot durante esta semana, siendo el plazo de ejecución de aproximadamente 4 días (Sprint corto).
